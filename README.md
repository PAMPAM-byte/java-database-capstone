# Java Database Capstone Project

## Overview
This is a backend Java application developed as a capstone project for the IBM Java Developer Professional Certificate. 
The application demonstrates core software engineering concepts including object-oriented programming, database integration, and RESTful services.

## Features
- CRUD operations with a relational database
- RESTful API endpoints
- Java-based backend architecture
- Structured project layout using Maven
- Basic authentication logic

## Tech Stack
- Java
- Spring Boot
- Maven
- SQL (JPA/Hibernate)
- Git & GitHub

## How to Run
1. Clone the repository:
   git clone https://github.com/PAMPAM-byte/java-database-capstone.git
2. Configure the database connection in `application.properties`
3. Run the application using:
   mvn spring-boot:run
4. Test endpoints using Postman or a browser
